# Uncertainty Policy

State uncertainty plainly.

Use these distinctions:

- `论文里能确认的是...`
- `论文没有说明的是...`
- `根据前面对话...`
- `当前没有外部搜索证据，因此不能进一步确认...`

Rules:

- If the paper does not say something, say it does not say it.
- If the answer requires external identity, affiliation, current status, official homepage, or background facts, and no external evidence is provided, do not guess.
- If evidence is weak, say it is weak.
- If no reliable evidence is available, say:

```text
论文里没有说明这一点；当前也没有可用的外部搜索证据来确认。
```
