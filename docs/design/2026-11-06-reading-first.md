# 阅读优先工作台 v2

本版按用户已确认的重写方向实施，分支 `feature/reading-first-codex-workbench`，基于 `origin/main`。参考用户 Chrome 中的 Notion 实际界面：窄幅正文、轻量顶栏、原位评论、可收起 Agent。

## 阅读流程

导入 PDF → OXR 自动按 20 页/10MB 拆批 → 校验完整覆盖 → 图文阅读 → 本机 Codex 翻译 → 中文/英文/中英对照。阅读正文最大宽度约 760px，白色背景、石墨色正文、灰色导航、低饱和蓝用于交互、浅黄用于划线。中文正文使用系统中文字体，英文正文 Georgia，导航系统 sans-serif。页面之外不堆展示卡片。

默认关闭 Agent。划选正文出现提问、高亮、批注动作。批注在对应块下展开，页边显示数量；总批注列表可回到原文。中文短语的精确偏移与对应英文句段同时保存；PDF 预览框出原块。语言模式、页码和滚动位置按论文保存。

## 实现边界

- React 阅读器；Electron 只管理窗口和本机服务生命周期。同一前端可在本机浏览器预览。
- `server/` 将已验证原型中的 OXR、PyMuPDF、Codex App Server 和持久化迁入正式仓库。HTTP 仅监听 127.0.0.1，校验 Host/Origin，资源路径白名单，渲染文本转义。
- 每篇论文独立讨论会话、批注和译文。翻译使用独立临时会话；讨论使用持久 thread，SSE 显示真实增量，工具保存批注并回读验证。
- 解析和翻译逐批落盘、支持暂停恢复；旧版项目数据不自动改写。v2 存在 `~/Documents/PaperReadingWorkbench/v2`，原型论文可显式复制导入，讨论会话重新建立。
- 暂不实现 Word/HTML 编辑、多人同步、逐词双语对齐、原生 PDF 批注和 Agent 任意系统操作。新版本不包含旧 DeepSeek 调用流程；旧代码保留供历史参考，生产入口切到新版。

## 验收

分批合并与缺页拒绝、双语锚点/错误版本拒绝、手动高亮与批注、真正 Codex 流式问答和工具回写、服务退出恢复、中文/双语切换、侧栏开关、原 PDF 跳转，均需实测。复用完整 CLIP 的已验证解析/译文做长文验收，并通过新服务重新解析少量真实 PDF 页验证新入口。
